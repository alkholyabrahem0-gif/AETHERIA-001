AETHERIA World Build 02 (mobile-friendly prototype)
Files:
- index.html
- style.css
- js/game.js

Open index.html via GitHub Pages. Three.js is loaded from a CDN, so internet is needed.
Controls: left virtual joystick to move, right side drag to rotate camera, Jump button; interact button appears near the glowing crystal.
Desktop: WASD/arrow keys, Space jump, E interact.
Quality default Low for Galaxy A13.
